Privacy Policy

Last updated: August 2026

chatmany is a self-hosted tool: this specific instance is run by its owner on their own Cloudflare account, for their own Instagram professional account. There is no shared service, no central chatmany company, and no data shared between separate people's deployments — everything described here lives only in this instance's own database.

What data this instance processes

Only what's needed to run comment-to-DM automations on the connected Instagram account:

DataFromWhy
Instagram user ID (IGSID), and public username if available Anyone who comments a matching keyword, or messages the connected account To send the automated reply and track that person's position in the funnel
The text of a matching comment or reply Same as above To check it against the configured keyword, and to prevent double-processing the same comment
Follow status (yes/no) and email address Same as above — only if the automation's optional follow-gate or email-ask step is turned on, and only if that person taps or replies to provide it To advance the funnel and deliver the reward
Funnel event log (comment matched, DM opened, button tapped, followed, email given, delivered) Generated by this instance as people move through a campaign Powers the dashboard the owner uses to see how their automations are performing
The connected account's own profile info and long-lived access token The Instagram account owner, via Meta's OAuth login Required to authenticate API calls made on the owner's behalf

What this instance does not do

  • No scraping — every read or write goes through the official Meta Instagram API
  • No password collection — Instagram login happens on Instagram's own page via OAuth
  • No selling, renting, or sharing this data with any third party
  • No advertising or tracking use of this data beyond running the owner's own automations

Where it's stored

In a Cloudflare D1 database belonging to this instance's owner. It isn't replicated to any other service, and the owner is the only party with access to it.

Retention

Data for a given person is kept for as long as their conversation state or event history is useful to the owner's automation — generally until the owner deletes the campaign or removes the record. There's no fixed automatic expiry today; see the deletion section below for how to have your data removed sooner.

Your choices

If you commented or messaged an account running chatmany and want your data deleted, see the data deletion instructions. The account owner can disconnect Instagram entirely at any time, which stops all further processing immediately.

Contact

Questions about this policy or a specific instance's data handling should go to that instance's owner — the Instagram account this bot is connected to.
