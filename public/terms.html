Terms of Service

Last updated: August 2026

chatmany is a self-hosted, open-source tool. This instance is deployed and operated by the owner of the Instagram professional account it's connected to — not by a separate company offering chatmany as a service. Using this instance means using that owner's automations.

What it does

Watches comments on posts the owner selects, matches them against keywords the owner configures, and sends automated replies via Instagram's official Messaging and Comments APIs — an opening private reply, an optional follow-gate, an optional email request, and a final delivery message, exactly as the owner has set them up.

Acceptable use

  • Only the official Meta Instagram API is used — no scraping, no unofficial endpoints, no credential collection.
  • Automations only act on comments and messages related to the connected account's own content.
  • The owner is responsible for the copy their automations send, and for complying with Meta's Platform Terms and Instagram's own Community Guidelines and automated-behavior policies.

No warranty

chatmany is provided as-is, without warranty of any kind. The owner of a given instance is solely responsible for how it's configured and what it sends.

Changes

Since each deployment is self-hosted and independently operated, changes to the underlying open-source project don't automatically apply to a running instance until its owner updates it.

Contact

For a specific chatmany instance, contact the Instagram account it's connected to.
